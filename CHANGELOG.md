## [Unreleased]

### Added

- CLI skeleton derived from DLoad: `bin/opmin`, DI container, base command, config attributes.
- YAML configuration `opmin.yaml` with strict validation, overrides through `OPMIN_*` environment variables and
  `--set`, JSON Schema `resources/opmin.schema.json`, `opmin init`.
- Command placeholders: `count`, `diff`, `optimize`, `apply-candidate`, `baseline`, `check`, `doctor`,
  `self-update`, `skill:install`, `skill:update`.
- Scoped PHAR (Box + PHP-Scoper), static binary build on native runners, CI on Testo.
- Playground: `playground-seeds/` and `bin/playground`.
